## 3단계 진행 방식
- **순서:** 묶지 않고 `beer.csv` 행 순서대로 한다(이미 시도별로 이어져 있다: 강원 10, 경기 31, 경상 16, 광주 1, 대구 12, 대전 11, 부산 22, 서울 86, 울산 3, 인천 6, 전라 7, 제주 11, 충청 7).
- **판정:** 확인하는 사람이 수동으로 한다. 네이버·카카오 지도에는 폐업 표시가 따로 없고 사장이 직접 내려야 사라지므로, 지도에 떠 있다는 것만으로는 영업 근거가 되지 않는다. 지도(방문자 리뷰 최신순)·인스타그램·검색을 사람이 보고 영업 / 폐업 / 미확인을 고른다. 지도·인스타그램은 자동 수집하지 않는다(이용약관).
- **기록:** 사람이 `beer.csv`를 직접 고친다(CONTRIBUTING과 같은 경로). 확인한 행은 `status`와 `last_verified`(확인한 날)를 적고, 판단이 서지 않으면 `미확인`으로 두되 날짜는 적는다. 고친 뒤 `python scripts/validate.py`(오류 0건)와 `python scripts/build.py`를 돌려 커밋한다. 폐업 판정 근거는 커밋 메시지에 한 줄 적는다. 불편하면 방식을 바꾼다.
- **진행 확인:** `validate.py` 마지막 줄 "재확인 n/223곳"(`last_verified`가 채워진 행 수). 이 표에는 따로 적지 않는다.
- **네이버 URL:** `naver.me` 단축 URL 59곳은 확인하면서 지도 주소창의 `https://map.naver.com/p/entry/place/<id>`로 바꿔 적는다. 단축 URL을 자동으로 풀지 않는다.
- **함께 볼 행:**
  - 몰티스 브루펍: 2단계에서 원본 설명 "10/02 영업종료"를 근거로 `폐업`으로 옮겼다. 사람이 확인하고 날짜를 적는다
  - 분점 이름 4곳(화이트래빗 마산점·이태원점, 어메이징브루잉컴퍼니 성수점·송도점): 지역명으로 붙인 것이라 공식 지점명인지 확인한다
  - 카브루_상색_브루어리: 네이버 지도 URL이 없다. 찾으면 채운다
