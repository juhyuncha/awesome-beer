# 개요

## 목표
2022-10 이후 멈춘 `resten1497/awesome-beer`(국내 크래프트 맥주 탭룸·브루펍·바틀샵 목록, 별 145)를 포크해 다시 관리한다. 검증된 최신 목록과 지도 페이지를 만들고, 직접 가본 곳은 블로그 후기와 잇는다.

## 범위
- 포함: 데이터 정리·재검증, 형식 검사·자동 생성, GitHub Pages 지도(정적, 서버 없음), 정기 재확인 절차
- 제외: 가게가 메뉴판을 직접 관리하는 서비스(원본 이슈 #8 제안), 리뷰·평점 기능, 지도 서비스 자동 수집

## 데이터 구조 (`beer.csv`)
| 필드 | 뜻 |
|---|---|
| sidoNm | 시도 묶음(강원, 경기, 경상, 광주, 대구, 대전, 부산, 서울, 울산, 인천, 전라, 제주, 충청) |
| name | 가게명. 분점은 지점명을 붙인다(예: 화이트래빗 이태원점) |
| address | 도로명주소. 첫 단어는 짧은 시도명(서울, 경북, 전북 등) |
| beerType | 탭룸 / 브루펍 / 바틀샵 / 기타 |
| desc | 특징 한 줄 |
| naverUrl | 네이버 지도 장소 URL(`map.naver.com/v5/entry/place/<id>` 또는 `naver.me` 단축) |
| homepage | 홈페이지. 가능하면 인스타그램 |
| x, y | 경도, 위도 |

## 용어
- **탭룸:** 양조하지 않고 맥주를 파는 곳
- **브루펍:** 매장에 양조 설비가 있거나, 자사 양조장 맥주를 파는 곳
- **바틀샵:** 병·캔 맥주를 파는 곳
- **기타:** 위에 들지 않는 곳(맥주 공방 등)
- **재확인:** 지도·인스타그램으로 영업 여부와 주소를 사람이 확인하는 일
